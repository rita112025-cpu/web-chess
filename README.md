# 簡單西洋棋（互動式新手教學）

純前端、無依賴的西洋棋。打開 `index.html`（或用任一靜態伺服器）即可使用。

## 功能
- **學習棋子**：6 種棋子 + 王車易位、吃過路兵、升變、將軍與將死，共 10 課，動手點擊學習
- **練習挑戰**：6 個關卡，成功與否依實際棋盤判定
- **自由對弈**：對戰電腦（隨機合法走子）或雙人同機；悔棋、新對局、翻轉棋盤
- 完整棋規：王車易位、吃過路兵、兵升變、將軍／將死／逼和、50 步規則、三次重複、子力不足

## 檔案
- `index.html`、`style.css`：頁面與樣式（含手機版）
- `engine.js`：棋規引擎，不依賴畫面
- `board.js`：棋盤繪製（自由對弈與教學共用）
- `app.js`：首頁導覽與自由對弈流程
- `lessons.js`：教學單元與挑戰關卡資料
- `session.js`：單一練習步驟的邏輯（選棋、走棋、成功判定、錯誤說明）
- `tutorial.js`：教學／挑戰的畫面流程
- `test.js`：棋規測試（perft 與特殊棋規）；`tutorial.test.js`：教學與挑戰測試

## 測試
```
node test.js
node tutorial.test.js
```
