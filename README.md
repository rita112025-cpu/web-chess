# 線上西洋棋 Web Chess

純前端西洋棋，打開網頁即可遊玩，無需安裝。

**立即遊玩：** https://rita112025-cpu.github.io/web-chess/

## 功能
- 完整棋規：王車易位、吃過路兵、兵升變、將軍／將死、逼和、50 步規則、三次重複、子力不足
- 對戰電腦（簡單／中等／困難）、線上對戰（建立房間，把邀請連結傳給朋友）或雙人同機
- 悔棋、翻轉棋盤、棋譜記錄（SAN）、吃子與子力差顯示
- 線上對戰時可以和對手聊天

## 檔案
- `index.html`：介面
- `engine.js`：棋規與 AI（alpha-beta 搜尋），已通過標準 perft 測試
