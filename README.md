# Royal Chess 皇家棋院

純前端西洋棋，打開網頁即可遊玩，不需安裝、不需建置。

**立即遊玩：** https://rita112025-cpu.github.io/web-chess/

## 功能

**棋規（完整）**
- 王車易位、吃過路兵、兵升變
- 將軍、將死、逼和
- 50 步規則、三次重複、子力不足和棋

**對戰模式**
- 對戰電腦：簡單／中等／困難三種難度（alpha-beta 搜尋）
- 雙人同機
- 線上對戰：建立房間，把邀請連結傳給朋友即可對戰

**線上對戰**
- 聊天（超過 200 字會提示，不會靜默截斷）
- 認輸、提議和棋（對方可接受或拒絕）
- 進行中按「新局」會先跳出確認
- 對手離線會即時提示；房客用同一個連結重連時，房主會把著法傳回，還原進行中的棋局
- 線上模式不能悔棋

**介面**
- Royal Chess 皇家棋院：SVG 棋子、深綠金色主題、落子動畫
- 支援手機版
- 悔棋（單機模式）、翻轉棋盤、棋譜記錄（SAN）、吃子與子力差顯示

## 怎麼玩

1. 點選自己的棋子，棋盤會標出可以走的位置。
2. 再點目標格就會走棋。
3. 兵走到底線時會跳出選單，選擇要升變成哪個棋子。
4. 線上對戰：房主按「建立房間」，把產生的連結傳給對方；對方打開連結就會加入，房客執黑。

## 本機執行

直接用瀏覽器開啟 `index.html` 即可對戰電腦或雙人同機。線上對戰需要網路連線（透過 PeerJS 雲端服務配對），建議用本機伺服器開啟，例如：

```bash
python -m http.server 8000
```

然後開啟 `http://localhost:8000`。

## 其他版本

`cline/simple-chess` 分支是另一個獨立的 **Simple Chess 入門教學版**：以隨機走子的電腦、10 課棋子與特殊規則教學、6 個練習挑戰為主，沒有線上對戰。
