# 簡單西洋棋（入門教學版）

純前端、無依賴的西洋棋。打開 `index.html` 即可遊玩。

## 功能
- 雙人同機、對戰電腦（隨機合法走子）
- 悔棋、新對局、翻轉棋盤
- 完整棋規：王車易位、吃過路兵、兵升變、將軍／將死／逼和、50 步規則、三次重複、子力不足

## 檔案
- `index.html`：頁面結構
- `style.css`：樣式（含手機版）
- `app.js`：介面與遊戲流程（點擊、電腦回合、悔棋）
- `engine.js`：棋規引擎（走法產生、將軍／和局判定、隨機電腦），不依賴畫面
- `test.js`：棋規測試（perft 與特殊棋規），執行 `node test.js`
